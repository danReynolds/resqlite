# Milestones

The curated, narrative arc of how Resqlite has evolved — what mattered, what
turned out to be a dead end in retrospect, where the headline numbers came
from. Written in blog voice for a reader who wants the story, not the data.

This file is updated **on request**, not per experiment. When the maintainer
asks for a milestone update, derive entries from:

- experiment writeups in this directory
- benchmark history in [`docs/experiments/history.json`](../docs/experiments/history.json)
  and result files under [`benchmark/results/`](../benchmark/results/)
- git log since the previous milestone entry
- transferable lessons recorded in [`JOURNAL.md`](JOURNAL.md)

Good triggers for a milestone entry: a benchmark crosses a meaningful
threshold, a direction graduates from `measurement-needed` → `accepted` or
`exhausted`, an accepted experiment changes the public API, a series of
related experiments ends with a clear story to tell. Cadence is naturally
slow — expect entries every ~10 experiments, not every PR.

This file will not be exhaustive. Entries are *curated* — the point is the
arc, not the changelog. For per-experiment data see
[`signals.json`](signals.json) and the writeups directly.
